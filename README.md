# soundcloud-rpc-medexplug
🎵 A plugin for [soundcloud-rpc](https://github.com/richardhbtz/soundcloud-rpc "soundcloud-rpc") electron client.

This plugin let's you turn your window into an eye pleasing mini-player. It is a little bit early for release. I am considering to make it a fully fledged, feature rich player for the entire window. For now, it works. 

## Features
 - Integrated with other plugins such as [playback speed](https://github.com/richardhbtz/soundcloud-rpc/blob/main/plugins/playback-speed.js "playback-speed.js")
 - Procedural accented color for the background
 - Vertical/Horizontal mode (scale the window as you please)
 - Clean mosaic background

## Installation

 1. Download the javascript file from the source.
 2. Hit F1 to open up the settings in soundcloud rpc
 3. Go to the plugins section and open the folder
 4. Put the file inside the folder
 5. Refresh and enable the plugin. Apply the changes
